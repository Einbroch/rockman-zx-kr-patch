# 록맨 ZX (NDS) 한글패치

닌텐도 DS 「ロックマンゼクス」(일본판, ARZJ) 한글패치입니다. 일본판 원문을 새로 번역했습니다.
롬은 들어 있지 않습니다. 직접 덤프한 일본판 롬에 패치를 적용해 주세요.

록맨 ZX 어드벤트는 아직 작업 전입니다.

## 적용

| 원본 롬 | 패치 | 결과 |
|---|---|---|
| `Rockman ZX (J)` 67,108,864바이트, CRC32 `B577BBE0` | `patch/zx_ko.xdelta` | 67,496,264바이트, CRC32 `391CF460` |

xdelta UI 또는 xdelta3 로 일본판 원본에 적용합니다.

```bash
xdelta3 -d -s "Rockman ZX (J).nds" patch/zx_ko.xdelta "Rockman ZX (K).nds"
```

결과 SHA-1: `BF74272008E551A2F4793D44B3F1EE3D755DA200`

## 들어간 것

- **대사·시스템 문장 전부**: 2,947개 메시지를 번역했습니다. 빈 메시지나 영숫자 표처럼 일본어가 없는 139개는 원문 그대로 둡니다.
  - 한글은 12px 가변폭 글꼴(갈무리11 바탕)로 나옵니다.
  - 글리프 994자는 롬 안에 압축해 상주시켜, 대사를 출력할 때 파일을 읽지 않습니다.
- **타이틀**: 로고 「록맨 젝스」, 오프닝 장면의 작은 로고, 시작 안내, 처음부터·이어서, 난이도, 반·에일.
- **서브 화면 네 쪽**(상태·아이템·옵션·미션):
  - 탭과 버튼
  - 플레이 타임·E크리스탈
  - 모델 이름
  - 아이템A~C
  - 옵션 표(버튼 배치·공격 모드·액션 모드)
  - 메인·서브 꼬리표
- **그 밖의 화면**:
  - 게임 오버 메뉴, 기록 화면 버튼, 미션 화면 꼬리표
  - 플루브 연구소(수리 화면), 시크릿 디스크 탭
  - 퍼즐 미니게임 라벨
  - 스테이지 표지(최단 기록·최고 점수)

## 일본어로 남는 것

- 버스터 에디트 화면(모델 FX)의 그림 글자, 그리고 모델 능력 화면 일부 조각
- 대화창 화자 이름표(얼굴 그림에 들어 있는 이름)

## 확인하지 못한 것

- 실기(DS 본체·플래시 카트)
- 에뮬레이터로 확인한 범위:
  - 타이틀
  - 오프닝
  - 첫 스테이지 대사
  - 서브 화면 네 쪽
- 다음 화면은 그림 데이터만 렌더해 확인했고, 게임 안에서 띄워 보지는 못했습니다:
  - 게임 오버
  - 기록 화면
  - 미션 화면
  - 수리 화면
  - 시크릿 디스크
  - 퍼즐
  - 스테이지 표지
- 통과 플레이

문제를 발견하면 이슈로 알려 주세요. 가능하면 화면 캡처와 그 장면까지의 진행 상황을 함께 적어 주세요.

## 빌드

Python 3, `ndspy`, `Pillow`, `keystone-engine` 이 필요합니다. 일본판 롬을 `Rockman ZX (J).nds` 이름으로 저장소 최상위에 두고:

```bash
python tools/build_zx.py
```

결과는 `out/zx_kr.nds` 이고, 위 표의 CRC32 와 같아야 합니다.

| 위치 | 내용 |
|---|---|
| `data/ko/zx/*.txt` | 번역 원고(`;JP` 원문 아래가 번역) |
| `tools/build_zx.py`, `tools/zxhook.s` | 한글 출력 엔진(ARM9 훅)과 빌드 |
| `tools/gfx_*.py`, `tools/logo_zx.py` | 그림 글자 |
| `HANDOFF.md` | 형식·엔진·그림 파일 조사 기록 |
